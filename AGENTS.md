# helgoland

Visual Exploration and Analysis of Sensor Web Data

Package manager: npm.

## Commands

- build: `npm run build`
- test: `npm test`
- lint: `npm run lint`

## Layout

- `doc/`
- `e2e/`
- `netlify/`
- `scripts/`
- `src/`

## Rules

- Run `npm test` before you say a change is done.
- Never commit secrets or `.env` files.
